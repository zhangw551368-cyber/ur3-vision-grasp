# 2026-08-31 真机执行归档

本目录汇总“启用新手眼标定文件以后，到右臂执行真机抓取”为止的两条已验证路线。所有新增 `运行.sh` 都只是调用原工作区中已经使用过的 ROS/抓取程序，不修改原程序。

## 结论

| 路线 | 用途 | 持续运行终端数 | 已有实机结果 |
|---|---|---:|---|
| A：HSV 三蓝块 | 固定颜色、三个蓝色物块连续抓放 | 9 | 3 个物块、16 段运动成功 |
| B：GraspNet 多样工件 | 法兰、金属环等 RGB-D 6DoF 连续抓放 | 10 | 大法兰和金属环连续抓放成功 |

两条路线共用终端 1～7。路线 A 再运行 `08A`、`09A`；路线 B 再运行 `08B`、`09B`、`10B`。同一路线的终端应分别保持运行，不要在同一个终端里依次覆盖长期运行的节点。夹爪激活、TF 检查和状态查询是短命令，可使用临时终端，不计入持续运行终端数。

## 新手眼标定文件

实际运行的是：

```text
/home/gzu/gzu_ws/calibration/handeye/right_arm_camera_eye_on_base_20260817_safe.launch
```

它使用 2026-08-17 标定数值的安全等价形式，发布：

```text
right_arm_base -> camera_link
```

RealSense 驱动继续发布：

```text
camera_link -> camera_color_optical_frame
```

不要同时启动旧的 `2026-8-17<0.00929.launch`、其他 base-to-camera 静态 TF 或 MoveIt Calibration 相机位姿发布器，否则相机坐标系可能出现多个父节点。

## 使用顺序

1. 阅读 [`00_总览与关键指令/README.md`](00_总览与关键指令/README.md)。
2. 按编号分别打开终端并运行各文件夹内的 `运行.sh`。
3. 先完成仅规划、目标复核和 RViz 审查。
4. 现场清空后，在示教器启动右臂 External Control。
5. 检查机器人、控制器、安全模式和夹爪状态。
6. 只有现场操作者明确确认后，才运行带“真机执行”字样的脚本。

## 目录用途

- `01`～`07`：两条路线共用的机器人、MoveIt、相机、标定、夹爪和碰撞环境。
- `08A`～`09A`：HSV 三蓝块路线。
- `08B`～`10B`：GraspNet 多样工件路线。
- `11_关键代码`：与本流程直接相关的原始代码快照、文件索引和带逐行中文解释的运行脚本说明。

## 重要限制

- 历史目标坐标只能用于复核，物体、棋盘、相机、桌子或机器人底座移动后必须重新识别和规划。
- 本目录没有复制任何历史 `.pkl` 轨迹缓存，避免把旧场景轨迹误用于当前真机。
- `execution.enabled` 默认必须为 `false`；路线 B 只有完成当轮规划和 RViz 审查后，才能临时改为 `true`，执行结束立即恢复为 `false`。
- 规划成功不等于允许执行。急停必须可触达，工作区必须无人，External Control 必须正常运行。
