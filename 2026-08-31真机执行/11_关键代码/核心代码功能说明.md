# 核心代码功能说明

## 共用链路

| 文件 | 输入 | 主要处理 | 输出/作用 |
|---|---|---|---|
| `right_arm_camera_eye_on_base_20260817_safe.launch` | 固定外参数值 | 发布唯一的 base-to-camera root TF | `right_arm_base -> camera_link` |
| `publish_real_environment_scene.py` | 环境 YAML | 构造机柜、绿桌碰撞体 | MoveIt PlanningScene |
| `activate_right_gripper.py` | ROS 参数 | 发送激活与打开命令 | Robotiq 输出话题 |

## HSV 三蓝块

| 文件 | 关键职责 |
|---|---|
| `blue_blocks_checkerboard_perception.py` | 订阅彩色图、对齐深度和内参；HSV 分割蓝块；提取中心和长轴；深度反投影；通过 TF 转到 base；识别棋盘放置点；发布 PoseArray/Marker。 |
| `validate_locked_blue_targets.py` | 连续采样当前物块；按空间距离关联历史锁点；计算位移与 MAD；只报告通过/失败，不发运动命令。 |
| `right_arm_three_blue_pick_place.py` | 读取配置和冻结目标；生成抓取、抬升、高位释放、撤离与回初始位；规划所有段；检查夹爪反馈；按顺序执行。 |
| `right_arm_visual_pick.py` | 提供 MoveIt 规划重试、轨迹时长/关节运动检查、TCP/tool0 换算、机器人状态门控、夹爪开闭和执行误差检查。 |

## GraspNet 多样工件

| 文件 | 关键职责 |
|---|---|
| `classify_pictured_objects.py` | 对彩色图做工件启发式分类与稳定；输出可视化和包含类别、像素中心、包围框的 JSON。 |
| `graspnet_inference_node.py` | 同步 RGB、aligned depth 和 camera info；检查 frame；建立 ROI 点云；调用 checkpoint；发布 Top-N 6DoF 候选和推理服务。 |
| `graspnet_pick_executor.py` | 将候选从相机系转到 base；检查桌面高度、工作区、夹爪宽度、接近方向和碰撞；规划 pre-grasp、grasp、lift、drop 与 return；执行时检查真机和 `gOBJ=2`。 |
| `multi_object_sequence.py` | 在相机无遮挡时冻结目标；为每个目标多次推理；规划全部连续轨迹；发布 RViz DisplayTrajectory；原子写入 JSON 和 `.pkl` 缓存。 |
| `execute_cached_sequence.py` | 检查 `--execute --yes`、执行锁、缓存路径、缓存年龄和关节起点；只执行已审查轨迹；失败时打开夹爪、撤离并回初始位。 |
| `geometry.py` | 齐次变换、四元数和抓取轴转换。 |
| `ros_image.py` | ROS Image 解码、深度米制转换、内参矩阵和 ROI 掩膜。 |
| `target_validation.py` | 冻结目标和当前检测之间的最近邻/漂移判断。 |
| `config.py` | 读取 YAML，解析相对路径并校验必要配置。 |

## 执行门控的代码顺序

```text
execution.enabled
-> 人工 EXECUTE 确认
-> 缓存年龄
-> 当前关节起点
-> External Control / 机器人 / 安全模式 / 控制器
-> 打开夹爪
-> 执行抓取轨迹
-> 闭合并要求 gOBJ=2
-> 抬升、释放、返回
-> 失败恢复
```
